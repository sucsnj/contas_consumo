# Contexto do Projeto - Contas

Leia este arquivo e os documentos abaixo ANTES de qualquer alteracao no projeto:

1. PROJECT_STATUS.md (raiz do projeto) - situacao atual, decisoes de negocio e etapas.
2. src/ - estrutura de codigo (components, features, hooks, lib, pages, store, types).

Regras do agente:

- Nao implementar funcionalidades de etapas anteriores sem atualizar este status.
- Nao duplicar regras de negocio; regras vivem no engine de calculo.
- Documentar alteracoes ao final em PROJECT_STATUS.md.

Comandos uteis:

- npm run dev - servidor de desenvolvimento
- npm run build - build de producao
- npm run lint - lint
